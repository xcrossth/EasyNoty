# ไฟล์ไอคอน EasyNoty

[English](README.en.md) | [สารบัญ](../../README.md)

แบบที่เลือกคือ N ริบบิ้นสีฟ้า/น้ำเงิน มีแกนแสงและวงโคจร บนพื้นน้ำเงินมืด ไม่ใช่พื้นโปร่งใส

| ไฟล์ | สถานะ |
|---|---|
| easynoty-icon-dark-v3.png | ต้นฉบับที่อนุมัติ 1254×1254 |
| easynoty-icon-dark-v3-64.png | ภาพตัวอย่าง 64×64 |
| easynoty-icon-keyed*.png | แบบทดลองพื้นเขียว ไม่ใช้ในแอป |
| easynoty-icon-transparent*.png | แบบทดลอง transparency ที่ไม่ได้เลือก ไม่ใช้ในแอป |

[EasyNoty.ico](../../windows/src/EasyNoty.Desktop/Assets/EasyNoty.ico) สำหรับ Windows มี 16, 20, 24, 32, 40, 48, 64, 96, 128 และ 256 px และถูกใช้กับ EXE, AppWindow และ tray แบบทดลองถูกเก็บไว้เป็นประวัติการออกแบบ อย่าเลือกแทน dark-v3 โดยไม่ตั้งใจ

![แบบที่เลือก](easynoty-icon-dark-v3-64.png)

ไอคอน Android ยังเป็น drawable ในโปรเจกต์ Android ไม่ได้เปลี่ยนเป็นชุด Windows โดยอัตโนมัติ
