# EasyNoty branding assets

[ภาษาไทย](README.md) | [Index](../../README.en.md)

The approved design is a cyan/blue ribbon N with an energy core and orbital arcs on dark navy, not a transparent background.

| File | Status |
|---|---|

| easynoty-icon-dark-v3-64.png | 64×64 preview |
| easynoty-icon-keyed*.png | Rejected green-background experiments, unused by the app |
| easynoty-icon-transparent*.png | Unselected transparency experiments, unused by the app |

The Windows [EasyNoty.ico](../../windows/src/EasyNoty.Desktop/Assets/EasyNoty.ico) includes 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 px frames. It is used by the EXE, AppWindow, and tray. Drafts are retained as design history; do not accidentally substitute them for dark-v3.

![Approved design](easynoty-icon-dark-v3-64.png)

Android still uses its own drawable; the Windows icon set has not automatically replaced it.
